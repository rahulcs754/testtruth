GitHub Action · StrykerJS · Free and open source

Are your tests actually testing anything?

TestTruth adds small bugs to the lines your PR changed and checks if a test fails. If no test fails, you see exactly which bug would have shipped.

Add to your repo View on GitHub

Why

Coverage is not enough

Coverage says a line ran. It does not say a test would fail if that line was wrong.

AI writes weak tests

expect(x).toBeDefined() gives 100% coverage and catches nothing. TestTruth shows it.

Fast on every PR

Only changed lines are mutated, so it runs in seconds to minutes, not an hour.

Nothing leaves CI

No account, no server, no AI. Uses StrykerJS in your own GitHub Actions run.

How to use it

  1. Install StrykerJS in your repo: 
    npm i -D @stryker-mutator/core @stryker-mutator/vitest-runner
    and add stryker.config.json: 
    { "testRunner": "vitest", "coverageAnalysis": "perTest" }
  2. Add the workflow .github/workflows/testtruth.yml: 
    on: pull_request
permissions: { contents: read, pull-requests: write }
jobs:
  testtruth:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with: { fetch-depth: 0 }
      - uses: actions/setup-node@v4
        with: { node-version: 22, cache: npm }
      - run: npm ci
      - uses: rahulcs754/testtruth@main
        with: { threshold: 60 }
  3. Open a PR. TestTruth posts one comment and updates it on every push.

How it works

1. Diff

Reads the changed line ranges from git diff.

2. Mutate

Runs Stryker with --mutate file:10-14 on only those lines.

3. Score

Caught ÷ (caught + missed), only for mutants on your lines.

4. Report

One PR comment, the job summary, and an optional failing check.
